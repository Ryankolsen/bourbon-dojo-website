# Bourbon Dojo — Marketing Website

Landing page for [Bourbon Dojo](https://apps.apple.com/us/app/bourbon-dojo/id6762319810), built with React + TypeScript + Vite, deployed on Netlify.

## Local development

```bash
pnpm install
pnpm dev
```

Opens at http://localhost:5173.

## Build

```bash
pnpm build    # outputs to dist/
pnpm preview  # serve the production build locally
```

## Deploy

Pushes to `main` auto-deploy via Netlify.
